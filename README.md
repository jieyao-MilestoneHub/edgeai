# Edge AI Learning Path

A collection of **labs, experiments, and overheated machines**.  
No titles, no trends — just hands-on exploration in **Edge AI**,  
where models *run hot*, *fail fast*, and *teach us how to build better systems*.

No hype. No shortcuts. Only labs that work.

---

## Lab Philosophy

- **Theory is not documentation — it's the foundation for action.**  
  We validate math through code, transforming abstraction into clarity.

- **Implementation is not a product.**  
  This is a safe sandbox for exploration, not a shipping pipeline.

- **Progress is iterative.**  
  We don’t rush results — we master the reasoning behind every step.

- **Understanding is not memorization.**  
  Expect to use pen and paper. This lab may trigger math allergies.

---

## Who This Lab Is For (including LLM Tuning Lab)

- Learners exploring **fine-tuning and experimental model alignment**  
- Engineers who want to **grasp theory by building from first principles**  
- Researchers and open-source builders who believe in **experiment-driven growth**

---

## Lab Structure

Each lab is structured into four main folders:

| Folder           | Purpose |
|------------------|---------|
| **`assets/`**     | Stores experiment logs, findings, and insights. |
| **`docs/`**       | Provides conceptual breakdowns and implementation guides. |
| **`lab_tasks/`**  | The active workspace where experiments are executed and evaluated. |
| **`scripts/`**    | Utility tools for environment validation, setup, and automation. |
